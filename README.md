# CodingTest

코딩테스트 문제를 풀면서 기록해두는 저장소입니다. 감을 잃지 않으려고 꾸준히 푸는 것에 의미를 두고 있습니다.

## 폴더 구조

`플랫폼 / 난이도 / 문제명` 순서로 폴더를 나눴습니다. 각 문제 폴더에는 문제 설명과 채점 결과가 담긴 README.md, 풀이 코드가 함께 들어 있습니다.

```
프로그래머스
├── 1
│   └── 42840. 모의고사
│       ├── README.md
│       └── 모의고사.java
├── 2
│   └── 42842. 카펫
│       ├── README.md
│       └── 카펫.java
└── 3
    └── 12979. 기지국 설치
        ├── README.md
        └── 기지국 설치.java
```

## 사용 언어

Java, SQL
